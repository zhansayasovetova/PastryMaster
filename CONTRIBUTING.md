# Contributing Guide

## Branching

Each team member works on separate features using Git branches.

Example:
- feature/ui
- feature/gameplay
- feature/sounds

---

# Commit Message Style

Use:
- feat:
- fix:
- style:
- refactor:
- chore:

Example:
feat: add recipe screen

---

# Code Style

- Use meaningful class names
- Keep methods short
- Separate UI and logic
- Dispose textures and sounds properly

---

# Pull Requests

Before merging:
- Test gameplay
- Check screen transitions
- Verify sounds and assets
- Resolve merge conflicts

---

# Team Workflow

Gameplay/UI:
- Screens
- Animations
- Sounds

Architecture/Logic:
- GameState
- Level logic
- Design patterns
- UML documentation
